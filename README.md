This project shows how to set up an automated process for deploying a Java application to Docker Hub using built-in GitHub Actions support. You will write a simple Java application, compile it, and package it into a Docker image using a Dockerfile and the Amazoncorretto:latest base image from Docker Hub. You will then connect that repository to GitHub and configure an automated build and deployment workflow with GitHub Actions to build and publish the Docker image to Docker Hub whenever you push code changes to the GitHub repository. This will securely log into Docker Hub using the stored secrets (DOCKER_USERNAME and DOCKER_PASSWORD), build the Docker image with a version tag, and upload that image to the user's Docker Hub account. Once this process is complete, you can use Docker commands to pull and run that image on any machine that runs Docker as part of this set of processes as you have built a CI/CD pipeline through automated builds and deployments to allow you to minimize your manual work and ensure your applications are consistently delivered.
